Cài đặt AI

Key lưu trong trình duyệt của máy này, app gọi thẳng tới Anthropic. Không nên nhập key trên máy dùng chung. Khi nhập brochure, file PDF được gửi tới Anthropic để đọc.

AI do đơn vị cung cấp, bạn không cần API key riêng. Nội dung bạn nhập và file PDF được gửi qua máy chủ của đơn vị tới Anthropic để xử lý. Không dùng tài liệu mật.
